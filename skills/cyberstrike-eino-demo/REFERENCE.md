# API / Reference (Example)

## HTTP `/api/skills/{id}`

- `resource_path`: package-relative path, for example `FORMS.md` or `scripts/payloads.txt`.
- `depth=summary`: summary and table of contents only; suitable for the first retrieval pass.

## Multi-Agent Runtime

- Use the Eino ADK **`skill`** tool to load skill packages progressively; optionally enable `multi_agent.eino_skills.filesystem_tools` to access files inside the package.
